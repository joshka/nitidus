# Conventions

- [Code](code.md): layout, ordering, imports, and function and module size.
- [UI](ui.md): look, color, components, and how screens are checked.
- [Mail](mail.md): how nitidus talks to Himalaya and treats mail as input.
- [Testing](testing.md): where tests go, how they read, and what they may touch.
- [Docs](docs.md): what comments and rustdoc should say.
- [Commits](commits.md): how changes are shaped and described.
- [Dependencies](dependencies.md): versions, features, licenses, and tool configuration.
- [Writing](writing.md): prose in Markdown, commit bodies, and PRs.

When feedback establishes a reusable rule, add it to the file that owns the topic, in the same terse
style. Record the rule's reason, not the conversation that produced it.
